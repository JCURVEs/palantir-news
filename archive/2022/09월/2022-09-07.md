## [Palantir] Palantir Foundry의 목적 기반 접근 제어(Purposes) 메커니즘

**분야:** 보안/거버넌스 | **중요도:** 8점

**원문발행일:** 2022-09-07T14:16:54.756000Z

**수집일:** 2026-10-20

**요약:**  
이탈리아어 원문은 COVID-19 대응 시 이질적인 의료 시스템 데이터를 통합하면서 수천 명의 사용자에게 데이터를 제공해야 했던 거버넌스 팀의 과제를 배경으로 한다. 기존 방식에서 접근 권한이 기술 팀으로 위임되면서 '누가, 어떤 데이터에, 왜' 접근하는지 추적하기 어려운 구조적 문제가 발생했다. Palantir Foundry의 'Purposes' 기능은 사용자가 개별 데이터셋이 아닌 특정 처리 목적에 대한 접근을 요청하도록 설계되어, 데이터 접근 범위를 목적에 필요한 최소한으로 제한한다. 데이터 거버넌스 팀은 각 목적에 대한 승인 시 결정의 정당성을 기록해야 하며, 데이터 관리자는 데이터 사용 승인 시에도 근거를 문서화해야 한다. 플랫폼은 민감한 작업 전후로 팝업 알림을 통해 사용자의 확인을 요구하는 '체크포인트'를 설정하여, 사전(a priori) 및 사후(a posteriori) 감사가 가능하도록 한다. 이를 통해 비기술적인 거버넌스 담당자가 권한 위임 없이 직접 접근을 통제하고, 모든 데이터 접근의 맥락과 이유를 감사할 수 있는 구조를 제공한다.

**쉬운설명:**  
COVID-19 당시 병원과 연구소 등 여러 기관의 데이터를 한데 모으는 과정에서, 누가 어떤 데이터를 왜 보는지 관리하기 어려웠던 문제를 해결하기 위해 설계된 도구입니다. 사용자가 특정 데이터 파일이 아니라 '환자 치료' 같은 명확한 목적을 선택해 접근을 요청하면, 시스템은 그 목적에 필요한 데이터만 제공하고 모든 승인 과정의 이유를 기록해 나중에 감사할 수 있게 합니다.

## [Palantir] Palantir, 브라우저 확장 프로그램 허용 목록을 코드화해 보안 관리 자동화

**분야:** 보안/거버넌스 | **중요도:** 7점

**원문발행일:** 2022-11-23T14:01:58Z

**수집일:** 2026-10-29

**요약:**  
브라우저 확장 프로그램은 강력한 권한을 요구해 악성 코드가 기업 네트워크로 침투할 위험이 크지만, 기존 거부 목록 방식으로는 관리가 어려웠다. Palantir은 osquery 데이터를 분석해 실제 사용 빈도가 높은 확장 프로그램만 선별하여 허용 목록(allowlist)을 구축했다. 이 목록은 내부 GitHub 저장소의 JSON 파일로 관리되며, 직원이 Pull Request를 통해 변경을 요청하면 CircleCI가 JSON 형식, 중복 여부, 웹 스토어 존재 여부를 자동 검증한다. 검증 통과 후 보안 팀이 CRXcavator 등 도구를 활용해 확장 프로그램의 권한과 네트워크 트래픽을 수동으로 심층 검토한다. Windows 환경에서는 GPO 레지스트리 값을 자동으로 갱신하는 스크립트가 실행되어 정책이 즉시 적용된다. 반면 macOS 환경에서는 Excavator 서비스가 JSON을 plist 파일로 변환해 Jamf Pro 관리자가 수동으로 업로드하도록 지원하며, Jamf API를 통한 완전 자동화는 아직 안전성 문제로 미해결 상태다.

**쉬운설명:**  
회사에서 쓸 수 있는 브라우저 플러그인 목록을 코드 파일로 만들어 두고, 직원이 새 플러그인을 쓰려면 그 파일에 추가 요청을 하면 시스템이 자동으로 형식과 안전성을 검사한 뒤 관리자가 최종 승인하는 방식이다.

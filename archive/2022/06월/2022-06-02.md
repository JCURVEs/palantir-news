## 10명 미만으로 3,000명 규모 보안 대응: Palantir의 사용자 참여형 탐지 전략

**분야:** 보안/거버넌스 | **중요도:** 8점

**Palantir 발행일:** 2022-06-02T18:29:15Z

**수집일:** 2026-10-29

*보안 경보의 홍수 속에서 핵심 위협을 식별하기 위해 사용자 참여를 탐지 로직에 통합한 Palantir의 운영 방식을 살펴본다.*

<mark>보안 팀은 매일 쏟아지는 수천 개의 경보 중 진짜 위협을 가려내야 하지만, 조직이 커질수록 이 작업은 인력 증가 없이 해결하기 어려운 과제가 된다.</mark> <mark>Palantir는 3,000명 이상의 직원과 수만 대의 호스트를 10명 미만의 보안 팀이 관리하는 이 비효율적인 구조를 어떻게 극복했는지 공개했다.</mark>

이 글의 핵심은 보안 탐지를 중앙 집중식 분석에서 '사용자 참여형 검증'으로 전환하는 메커니즘이다. Palantir는 SOAR(보안 오케스트레이션, 자동화 및 대응) 플랫폼과 Slack을 연동한 <strong>InfoSecBot</strong>을 통해 의심스러운 활동의 당사자에게 직접 확인을 요청함으로써, 보안 인력의 부담을 줄이고 응답 속도를 높이는 방식을 제안한다.

![Palantir 대표 이미지](https://miro.medium.com/1*t8pyU0Zt-3OoYRXOj0OYbQ.jpeg)

### Slack 연동으로 경보 처리 주체를 사용자까지 확장

Palantir의 보안 팀(<strong>CIRT</strong>)은 로그 데이터를 중앙 <strong>SIEM</strong>으로 수집하고 탐지 전략을 수립하지만, 모든 경보를 분석가들이 직접 처리하지 않는다. 대신 <strong>SOAR 플랫폼</strong>과 Slack을 연결한 <strong>InfoSecBot</strong>을 통해 경보의 당사자에게 직접 메시지를 전송한다.

이 시스템은 개인 알림, 개인 챌린지(확인/부인 버튼), 그룹 알림, <strong>MFA 챌린지</strong> 등 모듈을 조합해 복잡한 워크플로우를 구성한다. 예를 들어 사용자에게 15분 내 확인을 요청하고, 확인 시 추가 MFA 인증을 거쳐 경보를 종결하거나, 거부 또는 타임아웃 시 즉시 보안 팀으로 에스컬레이션한다.

### 계정 탈취와 자격 증명 변경 시 실시간 검증

공격자가 비밀번호를 탈취해 MFA를 우회하려 할 때, 사용자가 MFA 프롬프트를 거부하는 행위는 잠재적인 계정 탈취 신호로 간주된다. 이 경우 시스템은 해당 활동을 보안 팀에 알리고 분석가 검토를 트리거한다.

민감한 자원에 대한 인증 시도나 관리자 의한 비밀번호 변경, 패스워드리스 바이패스 코드 생성 시에도 <strong>InfoSecBot</strong>은 활동의 타임스탬프, 원본 IP, 관리자 이름 등을 포함해 사용자에게 즉시 알림을 보낸다. 사용자가 이 활동을 인지하지 못하거나 확인하지 않으면 경보는 자동으로 보안 팀으로 넘어간다.

### 팀 채널 대상 알림으로 내부 위협과 은폐 방지

계정 탈취 공격자는 Slack 메시지를 삭제하거나 음소거하여 경보를 숨길 수 있으므로, 개인 대상 알림만으로는 한계가 있다. 이를 보완하기 위해 Palantir는 특정 민감 활동에 대해 해당 사용자의 팀 전체가 포함된 Slack 채널로 알림을 보낸다.

이 방식은 팀 리더와 동료들이 구성원의 비정상적인 활동을 인지할 수 있게 하여, 개인이 경보를 무시하거나 은폐하는 상황을 방지한다. 채널 멤버십은 IDP(신원 제공자) 그룹 멤버십과 연동되어 자동 관리되며, 활동이 업무 기대와 일치하지 않을 경우 팀이 보안 팀에 에스컬레이션하도록 유도한다.

### 정리하면

Palantir의 방식은 보안 인력의 한계를 사용자 참여로 보완해 탐지 효율을 높였다는 점에서 검증된 운영 사례다. 그러나 사용자가 경보에 응답할 시간과 주의력이 필요하다는 운영적 비용이 존재하며, 공격자가 메시지 채널을 조작할 수 있는 위험성을 고려한 다층적 알림 전략이 필수적이다. 이 접근법은 모든 조직에 동일하게 적용되기보다, 조직의 문화와 기술 인프라에 맞춰 탐지 전략을 설계할 때 참고할 수 있는 프레임워크를 제공한다.

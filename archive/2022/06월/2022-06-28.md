## [Palantir] Palantir은 데이터 회사가 아니다: 데이터 기반 의사결정 소프트웨어 인프라

**분야:** 데이터 플랫폼 | **중요도:** 8점

**원문발행일:** 2022-06-28T15:32:00Z

**수집일:** 2026-10-09

**요약:**  
Palantir은 고객의 데이터를 수집, 저장, 판매하거나 다른 고객과 공유하지 않으며, 이는 데이터 브로커나 애그리게이터가 아님을 명확히 합니다. 대신 데이터 기반 의사결정을 위한 소프트웨어 인프라를 구축하고, 조직의 데이터, 분석 기능, 운영 실행을 연결하는 소프트웨어 라이선스를 제공합니다. Palantir은 데이터 처리자(Processor)로서 고객의 지시와 감독 하에 서비스를 제공하며, 고객의 데이터 주권을 엄격히 준수합니다. 이 글은 'Palantir 설명' 시리즈의 첫 번째로, Palantir의 비즈니스 모델과 데이터 거버넌스 원칙을 소개합니다.

**쉬운설명:**  
Palantir은 여러분의 데이터를 사거나 다른 사람에게 팔지 않는 소프트웨어 회사입니다. 대신, 흩어져 있는 데이터를 하나로 묶어 중요한 결정을 내리는 데 도움을 주는 도구를 빌려주는 역할을 합니다.

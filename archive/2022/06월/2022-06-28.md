## Palantir는 데이터가 아닌 소프트웨어를 판다

**분야:** 데이터 플랫폼 | **중요도:** 8점

**Palantir 발행일:** 2022-06-28T15:32:00Z

**수집일:** 2026-10-29

*데이터 판매가 아닌 소프트웨어 라이선스 모델로 작동하는 Palantir의 실제 업무 흐름과 보안 원칙을 살펴본다.*

<mark>수천 개의 병원이 각기 다른 수준의 개인보호장비(EPI) 재고를 보유하고 있고, 수요는 실시간으로 변하는 팬데믹 상황이었다.</mark> <mark>이러한 분산된 정보 속에서 어떤 병원에 어떤 물자를 우선 배분할지 결정하는 것은 단순한 데이터 집계로는 불가능한 복잡한 문제였다.</mark>

Palantir는 자사가 데이터 기업으로 오해받는 것에 대해 반박하며, 실제로는 데이터 기반 의사결정을 돕는 소프트웨어 인프라를 구축하는 기업임을 밝혔다. 이 글은 Palantir가 고객 데이터를 어떻게 취급하고, 어떤 방식으로 조직의 운영을 지원하는지 그 메커니즘을 구체적으로 설명한다.

### 데이터 판매가 아닌 소프트웨어 라이선스 모델

많은 기술 기업이 고객 데이터를 수집하거나 판매하여 수익을 창출하는 반면, Palantir는 이러한 방식을 채택하지 않는다. Palantir는 고객의 개인 데이터를 수집, 저장, 판매하지 않으며, 고객 데이터를 이용해 자체 AI 모델을 학습하거나 다른 고객에게 재판매하지 않는다.

대신 Palantir는 자사의 소프트웨어 솔루션을 <strong>라이선스</strong> 형태로 제공한다. 이는 고객이 자신의 데이터를 안전하게 유지하면서 분석과 운영 결정을 수행할 수 있는 프라이빗하고 보안이 강화된 환경을 구축하는 것을 의미한다.

### 분산된 데이터를 연결하는 의사결정 인프라

Palantir의 플랫폼은 조직 내 흩어져 있는 데이터, 분석 도구, 실제 운영 실행을 하나로 묶어주는 <strong>연결 조직</strong> 역할을 한다. 기존 시스템이 단절된 섬(Silo) 형태로 존재할 때, 이 플랫폼은 사용자가 필요한 정보를 정확한 시점에 접근할 수 있게 하여 의사결정 속도를 높인다.

이 과정에서 내려진 의사결정은 다시 원본 데이터로 피드백되어 조직의 지속적인 학습 흐름을 만든다. 이는 단순한 대시보드 제공을 넘어, 데이터가 실제 업무 운영에 어떻게 반영되는지를 관리하는 시스템적 접근이다.

### 팬데믹 중 의료 공급망 최적화 사례

Palantir는 COVID-19 팬데믹 기간 중 의료 기관들이 직면한 <strong>개인보호장비(EPI)</strong> 배분 문제를 해결하는 데 자사 소프트웨어가 사용되었음을 소개했다. 당시 수천 개의 병원은 각기 다른 재고 수준과 변동하는 수요를 가지고 있어, 중앙 집중식 관리가 어려운 상황이였다.

소프트웨어는 이러한 이질적이고 실시간으로 변하는 데이터를 통합하여, 어떤 병원에 어떤 물자를 공급해야 하는지 최적의 배분 결정을 내리는 데 기여했다. 이는 데이터가 단순히 보고되는 것이 아니라, 실제 물리적 자원 배분이라는 운영적 결과로 이어지는 과정을 보여준다.

### 데이터 처리자로서의 보안과 거버넌스

Palantir는 고객 데이터에 대해 '처리자(Processor)'의 역할을 수행하며, 데이터의 최종 통제권은 고객에게 있다. Palantir의 엔지니어는 고객이 설정한 권한과 감사 범위 내에서만 작업하며, 고객 간 데이터 이전은 계약상 명시된 의사가 있을 때만 가능하다.

이러한 구조는 Palantir가 국방, 정보, 국가 안보 등 극도로 민감한 환경에서 신뢰를 구축할 수 있었던 기반이 되며, 민간 부문에서도 동일한 수준의 보안 거버넌스를 적용한다는 점을 강조한다.

### 정리하면

이 발표는 Palantir가 데이터 소유권이나 거래를 통해 수익을 얻지 않는다는 점을 명확히 하여, 데이터 프라이버시 우려에 대한 직접적인 해답을 제시한다. 다만, 구체적인 보안 인증 세부 사항이나 다음 단계로 예고된 '목적 기반 <strong>데이터 거버넌스</strong>'의 기술적 구현 방식은 후속 글에서 다뤄질 예정이므로, 현재 시점에서는 비즈니스 모델과 데이터 취급 원칙에 대한 설명으로 한정된다.

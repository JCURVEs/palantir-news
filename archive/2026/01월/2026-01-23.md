## [Palantir] Palantir, VS Code 확장 프로그램 대규모 보안 관리 체계 구축

**분야:** 보안/거버넌스 | **중요도:** 8점

**원문발행일:** 2026-01-23T15:31:45.530000Z

**수집일:** 2026-10-26

**요약:**  
Palantir InfoSec 팀은 브라우저 확장 프로그램 관리 경험을 바탕으로 VS Code 확장 프로그램의 원격 코드 실행 위험을 차단하기 위해 자체적인 정적 분석 도구를 개발했다. 이 도구는 네트워크 호출, 셸 명령 실행, 하드코딩된 자격 증명, 코드 난독화 등 위험한 코드 패턴을 식별하고 NPM 감사 결과를 결합하여 확장 프로그램의 위험도를 평가한다. 정책은 버전 관리 저장소에서 관리되며, 개발자가 비즈니스 필요성을 명시한 Pull Request를 제출하면 InfoSec 엔지니어가 분석 결과를 검토하여 승인 여부를 결정한다. 승인된 목록은 CircleCI를 통해 Artifactory에 게시되고, Jamf Pro 및 Group Policy Objects를 이용해 Mac과 Windows 엔드포인트에 강제 적용된다. 강제 적용 전 개발자가 자신의 환경에 영향을 받는 확장 프로그램을 미리 확인할 수 있는 스크립트를 제공하여 수용성을 높였다. 결과적으로 Palantir는 공격 표면의 상당 부분을 차지하던 저사용 빈도 확장 프로그램의 위험을 통제하면서도, 개발자들이 검증된 도구만 사용하도록 유도하여 생산성을 유지했다.

**쉬운설명:**  
개발자들이 쓰는 편집기(IDE)에 설치하는 플러그인 중 일부가 해킹 도구로 위장해 회사 데이터를 탈취할 수 있다는 점을 인지하고, Palantir는 모든 플러그인을 자동 검사해 안전한 것만 허용하는 시스템을 만들었다. 이는 마치 공항 보안 검색대처럼 의심스러운 물건(코드)을 미리 스캔해서 위험한 것이 기내(컴퓨터)에 들어오지 못하게 막는 것과 같다.

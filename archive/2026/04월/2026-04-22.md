## [Palantir] Palantir, 보안 네트워크 환경에서 실시간 다국어 협업 구현

**분야:** 엔지니어링 | **중요도:** 6점

**원문발행일:** 2026-04-22T15:49:40.219000Z

**수집일:** 2026-10-29

**요약:**  
Palantir는 폐쇄형 보안 네트워크에서 표준 번역 도구를 사용할 수 없는 국방 및 정보 기관 고객의 다국어 협업 장벽을 해결하기 위해 문서 편집기 'Dossier'에 읽기 전용 번역 모드를 도입했다. 번역은 외부 서비스 대신 Palantir 내부의 언어 모델 서비스(LMS)를 통해 수행되어 데이터가 보안 네트워크를 벗어나지 않도록 했다. 수백 페이지에 달하는 문서의 성능과 품질을 균형 있게 맞추기 위해 문단, 목록, 표 셀 등 블록 단위로 텍스트를 분할(chunking)하여 번역 요청을 처리한다. 브라우저의 Intersection Observer API를 활용해 사용자가 현재 보고 있는 화면 영역의 블록만 우선 번역하는 지연 로딩 방식을 적용하여 백엔드 부하를 줄이고 UI 응답성을 유지했다. 실시간 협업 환경에서 다른 사용자의 편집이 감지되면 해당 블록의 캐시를 무효화하고 즉시 재번역하여 번역본의 최신성을 보장한다. 번역 품질을 높이기 위해 굵기나 링크 같은 인라인 포맷을 제거한 순수 텍스트로 전송하며, 이는 문장 구조가 깨져 발생하는 오번역(예: 'I love frontend engineering'을 단어로 쪼개면 'Je amour ingénierie frontend'로 오류 발생)을 방지하기 위함이다. 현재 번역된 뷰는 포맷이 없는 평문으로 제공되며, 향후 HTML 또는 Markdown 인식 번역 지원 등 모델 및 API 개선에 따라 포맷 보존 기능이 추가될 예정이다.

**쉬운설명:**  
보안 때문에 인터넷 번역기를 쓸 수 없는 환경에서, 문서의 보이는 부분만 골라 내부 시스템으로 보내 번역해 주는 방식이다. 문장을 단어로 쪼개면 의미가 깨지므로, 문단 단위로 보내고 화면에 보이는 것부터 순서대로 번역해 주는 구조다.

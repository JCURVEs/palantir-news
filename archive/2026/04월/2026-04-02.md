## [Palantir] Palantir 프론트엔드 엔지니어링: 백엔드 없는 크로스 앱 API 구축

**분야:** 엔지니어링 | **중요도:** 7점

**원문발행일:** 2026-04-02T16:18:22Z

**수집일:** 2026-10-29

**요약:**  
Palantir의 Gaia와 Workshop 등 여러 애플리케이션이 동시에 사용될 때, 네트워크 연결이 불안정하거나 지연되는 DDIL 환경에서 백엔드 의존성을 제거하기 위해 브라우저 API 기반의 프론트엔드 전용 통신 프레임워크를 개발했다. 초기 프로토타입이었던 'Gaia Controller'는 Workshop 위젯 형태로 구현되어 BroadcastChannel을 통해 타브 간 메시지를 주고받았으나, 다른 앱으로 확장하기 어려운 한계가 있었다. 이를 해결하기 위해 팀은 두 가지 핵심 동작을 분리하여 'Shared State'와 'Commands'라는 두 가지 표준 프레임워크로 재설계했다. 'Shared State'는 미디어 타입을 기반으로 상태 데이터를 정의하고 동기화하며, 'Commands'는 명령 ID와 요청 객체를 통해 다른 앱의 임의 로직을 호출하고 응답을 반환한다. 이 프레임워크들은 현재 AIP 에이전트가 사용자의 지도를 탐색하거나 주석을 달기 위한 도구로 활용되는 등 다양한 워크플로에 적용되고 있다. 모든 상호작용이 클라이언트 사이드에서 처리되므로, 백엔드 지연이 예측 불가능한 극한 환경에서도 안정적인 실시간 협업이 가능하다.

**쉬운설명:**  
인터넷 연결이 끊기거나 느린 환경에서도 여러 소프트웨어가 서로 데이터를 주고받을 수 있도록, 서버를 거치지 않고 브라우저 안에서 직접 대화하는 시스템을 만들었다. 마치 옆자리 동료와 눈빛과 손짓으로 바로 소통하듯, 지도 앱과 대시보드 앱이 실시간으로 정보를 공유하고 명령을 전달한다.

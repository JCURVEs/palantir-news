## Palantir OSDK, 비즈니스 로직을 코드로 직접 변환하는 방식

**분야:** 엔지니어링 | **중요도:** 7점

**Palantir 발행일:** 2024-02-16T17:21:46Z

**수집일:** 2026-10-29

*Palantir OSDK가 비즈니스 온톨로지를 개발용 SDK로 변환하여 AI 애플리케이션 구축 과정을 어떻게 단순화하는지 살펴본다.*

<mark>물류 센터에 화재가 발생했을 때, 기업은 피해 규모를 파악하기 위해 위성 이미지를 수집해야 하지만, 이를 위해 별도의 데이터 파이프라인과 보안 체계를 구축하는 데 상당한 시간이 소요된다.</mark> <mark>Palantir는 이러한 반복적인 시스템 연동 작업을 줄이기 위해 비즈니스 로직 자체를 개발 도구로 변환하는 접근법을 제시한다.</mark>

이 글은 Palantir AIP 시리즈의 일환으로, 온톨로지 소프트웨어 개발 키트(OSDK)를 통해 개발자가 비즈니스 개념을 직접 코드로 다루는 방식을 설명한다. Palantir는 가상의 기업 Titan Industries의 위성 임무 지정 사례를 통해 OSDK가 데이터, 로직, AI 함수를 어떻게 하나의 개발 환경으로 통합하는지 보여준다.

### 비즈니스 언어로 동작하는 SDK 생성 과정

Palantir의 OSDK는 온톨로지에 정의된 비즈니스 개념을 소프트웨어 개발 키트로 변환한다. 개발자는 <strong>Developer Console</strong>에서 필요한 온톨로지 객체, 링크, 액션, 함수를 개별적으로 선택하여 SDK의 범위를 정밀하게 제어할 수 있다.

이 과정에서 선택된 객체와 함수는 TypeScript, Python, cURL 형태로 자동 생성되며, 온톨로지가 변경되면 문서와 SDK도 자동으로 업데이트된다. 이는 개발자가 매번 수동으로 API 문서를 확인하거나 연동 코드를 수정할 필요가 없음을 의미한다.

### 위성 임무 지정 사례에서의 LLM 연동

Titan Industries 사례에서는 React 앱을 통해 화재가 발생한 물류 센터의 위성 이미지를 수집하는 워크플로우를 구축한다. 개발자는 <strong>AIP Logic</strong>에서 만든 LLM 기반 함수를 SDK에 포함시켜, 해당 함수가 최적의 위성을 자동으로 선택하도록 한다.

LLM 함수가 위성을 결정하면 그 결과는 즉시 온톨로지에 '태스킹 객체'로 기록된다. 이 객체는 이미 온톨로지에 정의된 보안 권한과 링크를 상속받으므로, 새로운 애플리케이션이 기존 시스템과 안전하게 상호작용할 수 있다.

### 보안 권한과 애플리케이션 유형 설정

<strong>Developer Console</strong>은 클라이언트 프론트엔드와 백엔드 서비스 두 가지 애플리케이션 유형을 지원하며, 각각의 보안 요구사항에 맞춰 권한 모델을 설정한다. 사용자 권한을 사용할 경우 기존 온톨로지의 보안 체계가 그대로 적용되어 별도 보안 구축이 불필요하다.

반면 애플리케이션 권한을 사용할 경우 생성된 <strong>서비스 사용자</strong>를 통해 접근을 제어한다. 이러한 설정은 개발자가 실시간으로 보안 영향을 확인할 수 있도록 도와주며, 의도치 않은 데이터 노출을 방지한다.

### 정리하면

OSDK는 비즈니스 로직을 중앙 집중된 온톨로지에 저장함으로써 새로운 애플리케이션 개발 시 시스템 통합 부담을 줄이는 메커니즘을 제공한다. 그러나 이 글은 특정 산업에서의 실측 성과 수치보다는 개발 워크플로우의 구조적 이점에 초점을 맞추고 있어, 실제 운영 환경에서의 성능 개선 정도는 추가 검증이 필요하다.

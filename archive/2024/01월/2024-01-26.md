## 분석가의 클릭이 모델을 실시간으로 고치는 Palantir의 사용자 중심 ML

**분야:** 국방/공공 | **중요도:** 8점

**Palantir 발행일:** 2024-01-26T15:59:23.147000Z

**수집일:** 2026-10-29

*정적 모델 출력을 실시간 상호작용으로 바꾸는 Palantir의 컴퓨터 비전 워크플로우 혁신을 살펴본다.*

<mark>위성 이미지를 분석하는 국방 분야 분석가들은 현재 배포된 컴퓨터 비전 모델들이 60~80%의 정확도에서 멈추어 있어, 모델이 놓친 군용 차량이나 선박을 매번 수동으로 확인해야 하는 부담을 안고 있습니다.</mark> <mark>모델의 오작동은 임무 수행 시 결정적인 지연을 초래하지만, 기존 워크플로우는 분석가가 모델에 피드백을 주거나 출력을 실시간으로 수정할 수 있는 통로를 제공하지 못했습니다.</mark>

Palantir는 이러한 '정적 모델'의 한계를 극복하기 위해 사용자가 모델의 입력과 출력에 직접 개입할 수 있는 '사용자 중심 기계 학습(UCML)' 서비스를 발표했습니다. 이 글은 분석가의 단순 클릭이 어떻게 모델의 검출 결과를 실시간으로 개선하는지, 그리고 그 뒤에서 작동하는 기술적 메커니즘을 구체적으로 설명합니다.

![Palantir 대표 이미지](https://miro.medium.com/v2/resize:fit:1200/1*HHX5DPDpXLlowejWoqPxXw.png)

### 정적 박스 대신 실시간 피드백 루프

기존 컴퓨터 비전 워크플로우는 분석가에게 노이즈가 섞인 정적 바운딩 박스만 제시하여, 모델 출력을 임무 맥락 내에서 실시간으로 정제할 수 없게 만들었습니다. Palantir는 분석가가 모델의 출력을 단순히 소비하는 것이 아니라, 누락된 객체를 지정하거나 오검출을 표시하는 등 직접 상호작용할 수 있어야 한다고 판단했습니다.

UCML 서비스는 분석가가 이미지에서 누락된 차량 하나를 지정하는 몇 번의 클릭만으로, 해당 피드백을 즉시 흡수하여 입력 이미지를 재처리합니다. 이를 통해 모델은 사용자가 관심 있는 객체를 더 많이 검출하거나, 이전에 표시된 오검출과 유사한 결과를 억제하는 방식으로 출력을 업데이트합니다.

### 베이스라인 검출과 템플릿 매칭의 융합 구조

UCML의 기술적 핵심은 <strong>베이스라인 검출기</strong>, <strong>커스텀 템플릿 매칭 딥러닝 모델</strong>, 그리고 <strong>융합 모듈</strong>이라는 세 가지 구성 요소의 조합입니다. 사용자가 제공한 양의(긍정) 및 음의(부정) 예시는 먼저 <strong>베이스라인 검출기</strong>가 생성한 각 검출 결과와의 유사도를 계산하는 데 사용됩니다.

이 <strong>유사도 점수</strong>를 기반으로 오검출과 유사한 박스는 억제되고, 사용자가 확인한 정확한 예시와 유사한 박스는 다시 표시되도록 재평가됩니다. 동시에, 사용자가 제공한 양의 예시는 유사한 객체를 찾아내는 데 특화된 딥러닝 모델의 입력으로 사용되며, 이 두 가지 출처의 결과는 <strong>융합 모듈</strong>을 통해 최종 검출 세트로 통합됩니다.

### 축적되는 이미지 템플릿과 조직 학습

UCML은 개별 세션의 피드백을 넘어, 분석가가 제공한 모든 피드백 포인트를 '<strong>이미지 템플릿</strong>'으로 저장합니다. 이 템플릿은 특정 관심 지역이나 여러 지역을 가로지르는 여러 분석가들로부터 축적될 수 있어, 조직 차원의 학습 자산이 됩니다.

분석가는 이러한 역사적 템플릿을 언제든 검색하여 활용함으로써, 새로운 이미지가 들어왔을 때 UCML 서비스가 실시간으로 검출 성능을 자동으로 개선하도록 할 수 있습니다. 이는 개별 분석가의 경험만이 아니라, 전체 의사결정 루프의 맥락을 모델에 반영하는 구조적 변화를 의미합니다.

### 정리하면

Palantir는 UCML이 임무 현장에서 모델의 실시간 상호작용성을 확보하여 의사결정 효율을 높이는 데 기여할 것이라고 강조했습니다. 다만, 이 글은 개념적 작동 방식과 시나리오를 중심으로 서술하고 있어, 실제 운영 환경에서의 정량적 성과 지표나 대규모 배포 시의 기술적 제약 사항은 명시되지 않았습니다.

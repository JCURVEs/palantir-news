## EU AI Act 대응: Palantir AIP의 데이터 거버넌스와 감사 로그 체계

**분야:** 보안/거버넌스 | **중요도:** 8점

**Palantir 발행일:** 2024-12-20T15:23:08.253000Z

**수집일:** 2026-10-29

*EU AI Act의 데이터 거버넌스 및 기록 보관 요구사항을 Palantir AIP의 보안 및 감사 기능으로 어떻게 구현하는지 살펴본다.*

<mark>생성형 AI 도입이 가속화되면서, 기업은 모델 성능뿐 아니라 데이터 처리 과정의 투명성과 규제 준수 여부를 입증해야 하는 새로운 과제에 직면했다.</mark> <mark>특히 EU AI Act와 같은 규제는 고위험 AI 시스템의 학습 데이터 관리부터 배포 후 감사까지 전 생애주기에 걸쳐 엄격한 기록과 통제 장치를 요구한다.</mark>

Palantir는 이러한 규제 환경을 해결하기 위해 Palantir AIP 플랫폼 내장된 데이터 거버넌스, 리스크 관리, 기록 보관 기능을 어떻게 활용하는지 상세히 설명했다. 본 글은 Palantir가 제시한 접근 방식이 데이터 접근 제어부터 모델 평가, 감사 로그 관리까지 어떻게 연결되는지 분석한다.

### 데이터 접근 제어와 민감 정보 보호

Palantir AIP는 SSO와 MFA를 통한 강력한 인증과 역할 기반 권한 부여(RBAC)를 기본으로 하여 사용자가 권한 범위 내 데이터에만 접근하도록 통제한다. 특히 <strong>Restricted Views</strong> 기능을 통해 행(row)이나 열(column) 단위로 접근 권한을 세분화하여, 특정 민감 데이터가 오용되는 것을 원천적으로 차단한다.

데이터 편향 리스크를 줄이기 위해 Sensitive Data Scanner(SDS)가 활용된다. 이 도구는 성별, 연령, 주소 등 모델 결과에 부당한 영향을 미칠 수 있는 속성을 자동으로 식별하고 마킹하여, 해당 데이터가 모델 학습이나 추론 과정에서 부적절하게 사용되지 않도록 통제한다. 또한 Checkpoints 애플리케이션을 통해 관리자 권한이 없는 사용자가 특수 카테고리 데이터를 처리할 때 그 이유를 명시하도록 요구하여, 데이터 처리의 정당성을 확보한다.

### 데이터 정제 과정의 추적과 모델 평가

EU AI Act 제10조는 고위험 AI 시스템의 학습 데이터가 데이터 거버넌스 관행에 따라 관리되어야 한다고 규정한다. Palantir는 Pipeline Builder와 Contour 같은 노코드 도구와 Code Repositories 같은 프로코드 환경을 제공하여, 기술 수준에 관계없이 데이터 라벨링, 정제, 집계 작업을 수행할 수 있게 한다.

이 과정에서 <strong>Data Lineage</strong> 기능은 원시 데이터 수집부터 최종 데이터셋 생성까지의 모든 단계를 동적 시각화 형태로 기록한다. 이는 기술 문서화 요구사항을 충족시키는 동시에 데이터 품질의 투명성을 보장한다. 모델 배포 전에는 <strong>AIP Evals</strong>를 사용하여 생성형 AI의 비결정성을 테스트하고, 단위 테스트 및 체계적인 리뷰를 통해 프로토타입이 프로덕션 환경에서 일관된 성능을 내는지 검증한다.

### 감사 로그와 온톨로지 변경 이력 관리

EU AI Act 제12조는 고위험 AI 시스템이 이벤트 로그를 자동으로 기록해야 한다고 요구한다. Palantir는 모든 플랫폼의 감사 로그를 디스크에 기록한 뒤 24시간 이내에 AWS S3이나 Azure Blob Storage 등 환경별 스토리지 버킷으로 아카이브한다. 고객은 이 로그를 플랫폼 내 데이터셋으로 내보내거나 외부 SIEM 시스템으로 전송하여 보안 모니터링에 활용할 수 있다.

데이터 해석의 기준이 되는 <strong>Palantir Ontology</strong>의 변경 사항은 특히 민감하게 관리된다. 온톨로지 변경은 주로 'Actions'를 통해 실행되며, <strong>Action Log</strong> 기능은 이러한 결정과 그 맥락을 객체 타입으로 구조화하여 기록한다. 또한 Edit Log는 개별 객체의 속성이 누구에 의해, 언제, 어떻게 변경되었는지 상세히 추적하여 데이터 무결성과 규제 준수성을 입증하는 근거 자료로 활용된다.

### 정리하면

Palantir AIP는 데이터 접근 통제, 정제 과정 추적, 모델 평가, 감사 로그 관리까지 AI 생애주기의 핵심 규제 요소를 플랫폼 기능으로 통합하여 제공한다. 이는 조직이 EU AI Act 등 신규 규제에 대응하기 위한 기술적 기반을 마련해 주지만, 구체적인 규제 준수 성과 수치보다는 프로세스 자동화에 초점을 맞추고 있다. 향후 커스텀 애플리케이션을 통한 맞춤형 컴플라이언스 전략은 후속 자료에서 더 자세히 다뤄질 예정이다.

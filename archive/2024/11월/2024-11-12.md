## [Palantir] Palantir의 소프트웨어 공급망 보안(SSCS) 프로그램: 위협 모델링과 제로 트러스트 기반 인프라 구축

**분야:** 보안/거버넌스 | **중요도:** 8점

**Palantir 발행일:** 2024-11-12T18:07:54.951000Z

**수집일:** 2026-10-29

**요약:**  
Palantir는 국가 단위 공격자(APT)와 공급망 공격에 대비하기 위해 '빠르게 움직이고 안전하게 보호한다'는 원칙 아래 소프트웨어 공급망 보안(SSCS) 프로그램을 출범시켰다. 외부 SaaS 플랫폼 의존도를 낮추고 FedRamp 인증을 받은 자체 호스팅 인프라를 구축하여, 네트워크 접근을 패스워드리스 SSO 기반의 풀 터널 VPN으로 제한하는 제로 트러스트 체계를 적용했다. 소스 코드는 GitHub Enterprise에 저장하고, CircleCI의 에피메랄 노드에서 빌드하며, Artifactory에 아티팩트를 저장한 뒤 Apollo를 통해 배포하는 파이프라인을 구성했다. 특히 1만 개 이상의 저장소에 대한 보안 설정을 중앙 집중식 YAML 파일 한 줄 변경으로 전파하는 내부 도구가 존재했으나, 이는 보안 제어를 대량으로 비활성화할 위험이 있어 위협 모델링 과정에서 주요 리스크로 식별되었다. CISO 주도 하에 개발팀 인터뷰와 다이어그램을 통해 실제 업무 흐름과 의도된 사용 간의 불일치를 파악하고, 소스 제어부터 배포까지 5개 핵심 영역에 대한 리스크와 완화 조치를 정의했다. 이 프로그램은 모든 커밋의 암호화 서명, 하드웨어 기반 서명, 최소 권한 원칙, 그리고 아티팩트의 종단 간 프로브넌스(출처 추적)를 보장하는 것을 목표로 하며, 향후 세부 구현 방안은 후속 글에서 다룰 예정이다.

**쉬운설명:**  
Palantir는 해커가 소프트웨어 개발 과정에 악성 코드를 숨겨 넣는 것을 막기 위해, 외부 서비스 대신 자체 서버를 직접 관리하며 모든 개발 단계에서 암호화 서명과 출처 추적을 의무화하는 시스템을 만들었습니다. 이는 마치 공장 생산 라인에서 각 부품의 제조자와 이동 경로를 실시간으로 검증하여 위조 부품이 최종 제품으로 들어가는 것을 원천 차단하는 것과 같은 원리입니다.

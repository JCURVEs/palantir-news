## 분리된 네트워크와 보안 등급 사이, Palantir의 국방 협업 방식

**분야:** 국방/공공 | **중요도:** 8점

**Palantir 발행일:** 2023-06-26T18:32:35Z

**수집일:** 2026-10-29

*보안 등급과 네트워크 단절이라는 장벽을 넘어서기 위한 Palantir의 데이터 중심 협업 아키텍처를 살펴봅니다.*

<mark>미국 합동군과 동맹국들은 전장에서 서로 다른 보안 등급의 데이터를 실시간으로 공유해야 하지만, 기존 시스템은 이러한 이질적인 환경을 연결하는 데 한계가 있었습니다.</mark> <mark>특히 단절되거나 대역폭이 낮은 환경에서는 정보의 지연과 분리가 작전 효율을 떨어뜨리는 주요 원인이 되었습니다.</mark>

Palantir는 2023년 6월 블로그를 통해, 이러한 문제를 해결하기 위해 보안 등급을 인지하는 데이터 중심 환경을 구축했다고 발표했습니다. 이 글은 Palantir의 <strong>Secure Collaboration</strong> 제품군이 어떻게 보안과 협업을 동시에 충족시키며, 동맹국 간의 작전 실행을 가속화하는지 그 메커니즘을 상세히 설명합니다.

### 보안 등급을 인지하는 데이터 통합 아키텍처

Palantir는 플랫폼의 핵심으로 '보안 등급을 인지하는 공유 의미론적 계층'을 제시합니다. 이는 서로 다른 출처에서 온 데이터를 하나의 공통된 언어로 구조화하되, 각 데이터 조각이 가진 보안 등급을 유지하면서 통합하는 방식입니다.

이 구조 덕분에 사용자는 자신의 권한(역할, 계급, 환경)에 따라 접근할 수 있는 정보만 자동으로 필터링되어 표시됩니다. Palantir는 CNSSI 1253, ICD 503, NIST SP 800-53 등 엄격한 외부 검증 인프라 표준을 준수하며, IL2부터 TS/SCI까지 다양한 보안 등급 인증을 획득했습니다.

### 단절된 네트워크에서도 유지되는 실시간 동기화

전장 환경에서는 인터넷 연결이 끊기거나 대역폭이 극도로 제한되는 경우가 많습니다. Palantir의 솔루션은 이러한 <strong>단절·간헐적·저대역폭(DIL) 환경</strong>에 최적화되어, 오프라인 상태에서도 데이터를 큐잉(queueing)하고 연결이 복구되면 자동으로 동기화합니다.

이 과정에서 데이터의 중복이나 충돌을 방지하여, 모든 사용자가 최신 상태의 단일 데이터 소스(Single Source of Truth)를 기반으로 의사결정을 내릴 수 있도록 합니다. 이는 정보의 위변조 위협을 줄이고 상황 인식(Situational Awareness)을 높이는 데 기여합니다.

### Briefings, Chat, Gaia로 이어지는 협업 도구군

Palantir는 보안된 협업을 위해 Briefings, Chat, <strong>Dossier</strong>, <strong>Gaia</strong> 등 일련의 도구들을 제공합니다. 예를 들어, <strong>Gaia</strong>는 지리공간 지휘통제 기능을 통해 전술적 정보와 지형 데이터를 하나의 화면에 통합하고, Chat은 보안 등급이 다른 사용자 간에도 데이터가 자동으로 검열된 채로 메시지를 주고받을 수 있게 합니다.

Briefings에서는 사용자가 다른 애플리케이션에서 데이터를 드래그 앤 드롭하여 슬라이드를 만들 수 있으며, 이때 삽입된 지도나 데이터는 원본이 업데이트되면 자동으로 갱신됩니다. 이러한 도구들은 모두 동일한 데이터 자산에 기반하므로, 정보 분석가부터 작전 지휘관까지 동일한 최신 정보를 공유하며 협업할 수 있습니다.

### 정리하면

Palantir의 <strong>Secure Collaboration</strong>은 보안 등급과 네트워크 단절이라는 국방 분야의 고질적 문제를 데이터 아키텍처 차원에서 해결하려는 시도입니다. 다만, 이 발표는 플랫폼의 기능적 메커니즘과 보안 준수 사항에 집중하고 있어, 실제 작전에서의 의사결정 시간 단축이나 오류 감소와 같은 정량적 성과 지표는 제시하지 않았습니다. 따라서 이 기술이 현장의 작전 효율에 미치는 구체적인 영향은 향후 실제 적용 사례를 통해 더 확인될 필요가 있습니다.

## [Palantir] Palantir, Apollo를 통해 IL6 보안 요구사항 충족 방법 공개

**분야:** 보안/거버넌스 | **중요도:** 8점

**원문발행일:** 2023-02-28T15:54:42.441000Z

**수집일:** 2026-10-10

**요약:**  
Palantir은 Apollo 플랫폼을 기반으로 국방정보시스템국(DISA)의 Impact Level 6(IL6) 임시 인가를 획득하여 미국 정부 클라우드 서비스의 보안 기준을 충족했습니다. Apollo의 내장된 컨테이너 취약점 스캐닝, 변경 요청(CR) 승인 프로세스, 그리고 네트워크 경계를 넘는 자동 배포 기능을 통해 NIST 리스크 관리 프레임워크(RMF)의 주요 제어 항목을 자동화했습니다. 이를 통해 격리된 환경에서도 취약점을 신속하게 탐지하고 패치하며, 인프라와 설정을 분리하여 장애 시 빠른 복구와 격리가 가능하도록 했습니다.

**쉬운설명:**  
Palantir의 Apollo는 정부 기관이 요구하는 최고 수준의 보안 기준(IL6)을 충족하기 위해 소프트웨어의 취약점을 자동으로 찾아내고, 변경 사항을 엄격하게 승인하며, 문제가 발생했을 때 신속하게 복구할 수 있도록 돕는 관리 도구입니다.

## Palantir Foundry, Azure 마켓플레이스 상장으로 배포 속도 높인다

**분야:** 기업/파트너십 | **중요도:** 7점

**Palantir 발행일:** 2023-01-25T12:01:05.477000Z

**수집일:** 2026-10-29

*클라우드 인프라와 데이터 분석 플랫폼의 결합이 기업 의사결정 속도에 미치는 영향을 살펴본다.*

<mark>글로벌 경제 불확실성 속에서 기업은 보호되고 신뢰할 수 있는 통합 데이터에 접근하는 것이 비즈니스 가치 창출의 핵심 과제로 떠올랐다.</mark> <mark>특히 기존에 구축해 둔 클라우드 인프라를 그대로 활용하면서 데이터 분석 역량을 강화하려는 수요가 커지고 있다.</mark>

Palantir는 이러한 요구에 부응하기 위해 Foundry 플랫폼을 Microsoft Azure 마켓플레이스에 공식 출시했다. 이번 발표의 핵심은 단순한 소프트웨어 배포가 아니라, Azure의 보안 인프라와 데이터 서비스와 Foundry의 온톨로지 엔진을 어떻게 결합하여 운영 의사결정을 가속화하는지에 있다.

![Palantir 대표 이미지](https://miro.medium.com/v2/resize:fit:1200/1*pPXEiO4obenOJ8SBdOHa4A.png)

### Azure 인프라와 Foundry 온톨로지의 결합 구조

Foundry는 Azure의 신뢰할 수 있는 보안 인프라와 글로벌 상업적 네트워크를 활용하여 배포 속도를 높인다. 이 과정에서 Foundry의 핵심 기능인 온톨로지 기반 운영 체제가 Azure의 데이터 서비스와 직접 연결된다.

구체적으로 Foundry는 Azure Data Lake, Synapse Analytics, Power BI, Dynamics 365, Teams 및 Industry Clouds와 같은 네이티브 서비스와 통합된다. 이를 통해 고객은 기존 Azure 데이터 서비스 투자가 낭비되지 않고, Palantir의 소프트웨어 정의 데이터 통합(SDDI)을 통해 새로운 분석 제품으로 확장될 수 있다.

### 기존 Azure 계약(MACC)을 활용한 구매 및 비용 관리

Azure 마켓플레이스 상장은 구매 및 청구 프로세스의 간소화를 의미한다. 고객은 별도의 신규 계약 없이 기존에 보유하고 있는 <strong>Microsoft Azure Consumption Commitment(MACC)</strong>를 사용하여 Foundry 라이선스와 인프라 비용을 결제할 수 있다.

이러한 결제 구조는 IT 예산 관리의 복잡성을 줄이고, 클라우드 자원 소비와 함께 데이터 분석 플랫폼 도입을 동일한 계약 체계 내에서 처리할 수 있게 한다.

### ERP 통합 가속화를 위한 HyperAuto 활용

에너지, 리테일, CPG 등 다양한 산업에서 Palantir와 Microsoft는 공동으로 시장 진출 기회를 모색하고 있다. 특히 SAP 및 기타 ERP 시스템의 통합을 위해 <strong>Palantir HyperAuto</strong>를 활용하여 데이터 지형을 통합하는 전략을 제시한다.

HyperAuto는 SAP on Azure 전환 과정을 가속화하며, 복잡한 데이터 구조를 정리하여 수 시간 내에 인사이트를 도출할 수 있도록 지원한다. 이는 데이터 기반 의사결정까지의 시간을 단축하는 구체적인 메커니즘으로 작용한다.

### 대규모 차량 데이터 처리 사례: Wejo

연결 차량 기업 <strong>Wejo</strong>는 Foundry의 기능을 최적화하는 파트너로서, 스마트 모빌리티 솔루션을 제공한다. <strong>Wejo</strong>의 데이터는 920억 건 이상의 차량 주행 기록과 19.5조 개 이상의 데이터 포인트로 구성된다.

이러한 방대한 데이터 규모는 Foundry가 Azure 환경에서 대규모 실시간 또는 준실시간 데이터를 처리하고, 다양한 산업의 비즈니스 혁신 및 성장에 기여할 수 있는 능력을 보여준다.

### 정리하면

이번 발표는 Foundry가 Azure 생태계 내에서 어떻게 배포되고 통합되는지에 대한 기술적 및 상업적 프레임워크를 명확히 했다. 다만, 구체적인 성능 향상 수치나 ROI 지표는 제시되지 않았으며, 실제 운영 환경에서의 효율성 증대는 각 고객의 데이터 규모와 통합 범위에 따라 달라질 수 있다.

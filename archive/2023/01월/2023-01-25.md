## [Palantir] Palantir, Microsoft Azure에서 Foundry 서비스 제공 개시

**분야:** 기업/파트너십 | **중요도:** 8점

**원문발행일:** 2023-01-25T12:01:05.477000Z

**수집일:** 2026-10-10

**요약:**  
Palantir는 자사의 데이터 분석 플랫폼인 Foundry를 Microsoft Azure에서 사용할 수 있게 되었다고 발표했다. 이를 통해 고객은 Azure의 신뢰할 수 있는 인프라와 글로벌 상업적 네트워크를 활용하여 소프트웨어를 빠르게 배포할 수 있다. 또한 Azure Data Lake, Synapse Analytics, Power BI 등 기존 Azure 데이터 서비스와의 통합을 지원하여 데이터 기반 의사결정을 강화한다. 고객은 기존 Microsoft Azure Consumption Commitment(MACC)를 사용하여 라이선스 및 인프라 비용을 결제할 수 있다.

**쉬운설명:**  
Palantir의 데이터 분석 도구인 Foundry를 이제 Microsoft의 클라우드 서비스인 Azure에서도 바로 설치하고 사용할 수 있게 되었습니다. 이는 기업들이 이미 사용 중인 Microsoft 클라우드 환경에서 데이터를 더 쉽고 빠르게 분석할 수 있게 해줍니다.

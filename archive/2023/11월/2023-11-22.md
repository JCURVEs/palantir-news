## 키워드 검색을 넘어 의미로 답을 찾는다: Palantir AIP 시맨틱 검색 워크플로

**분야:** AI/에이전트 | **중요도:** 8점

**Palantir 발행일:** 2023-11-22T19:14:25.358000Z

**수집일:** 2026-10-29

*비정형 데이터의 의미적 유사성을 활용해 LLM 기반 코파일럿을 구축하는 Palantir AIP의 7단계 워크플로를 살펴본다.*

<mark>기업 내 티켓팅 시스템이나 이메일에 흩어져 있는 해결책은 키워드 검색으로는 찾기 어렵다.</mark> <mark>'페이스 마스크'와 '페이스 커버링'처럼 표현은 다르지만 의미가 같은 정보들을 연결하는 것이 핵심 과제다.</mark>

Palantir는 AIP(AI Platform)를 이용해 이러한 비정형 데이터를 의미 기반 검색으로 전환하는 과정을 7단계로 나누어 설명했다. 이 글은 데이터 연결부터 최종 애플리케이션 배포까지의 구체적인 기술적 흐름을 취재한다.

![Palantir 대표 이미지](https://miro.medium.com/v2/resize:fit:1200/1*hLlNnVd2SWGxwXPkiXNufA.gif)

### 데이터 복제 없는 연결과 의미 벡터 생성

Palantir는 기존 클라우드 데이터 플랫폼의 자산을 AIP에 등록할 때 데이터를 물리적으로 복사하지 않는 Virtual Tables 기능을 사용한다. 이를 통해 빅쿼리(BigQuery)에 있는 트러블 티켓 데이터를 즉시 AIP 환경에서 활용할 수 있다.

다음 단계로 <strong>Pipeline Builder</strong>를 사용해 자연어 프롬프트로 데이터 정제 단계를 구성하고, OpenAI의 ada 모델을 호출해 텍스트를 임베딩 벡터로 변환한다. 이 벡터는 단어의 문법적 관계가 아닌 의미적 유사성을 수치화하여, '페이스 마스크'와 '페이스 커버링'이 서로 가깝게 위치하도록 만든다.

### 온톨로지 기반 벡터 스토어와 검색 함수

생성된 임베딩은 Palantir의 핵심 개념인 온톨로지(<strong>Ontology</strong>) 객체에 저장된다. 온톨로지는 비즈니스 프로세스의 실시간 결정 그래프 역할을 하며, LLM이 기업 데이터를 안전하게 상호작용할 수 있는 기반이 된다.

개발자는 이 온톨로지 객체를 대상으로 K-최근접 이웃(KNN) 알고리즘을 적용하는 커스텀 함수를 작성한다. 이 함수는 사용자 입력 텍스트의 임베딩과 저장된 티켓 임베딩 간의 유사도를 계산해 가장 관련성 높은 결과를 반환한다.

### LLM 코파일럿과 워크숍 애플리케이션 구성

<strong>AIP Logic</strong>은 코딩 없이 LLM 기반 함수를 구축하는 환경으로, 앞서 만든 시맨틱 검색 함수를 '도구'로 등록한다. LLM은 이 도구를 호출해 유사한 과거 문제를 찾고, 그 해결책을 현재 상황에 맞게 요약하여 단계별로 제시한다.

최종적으로 <strong>Workshop</strong>을 사용해 사용자 인터페이스를 구성한다. 사용자가 문제를 입력하면 시스템은 온톨로지를 검색해 과거 해결 사례를 바탕으로 가장 효과적인 액션을 제안한다. 이 과정에서 AIP는 코파일럿의 추론 과정(chain of thought)을 투명하게 보여줘 신뢰성을 확보한다.

### 정리하면

이 워크플로는 비정형 데이터에 잠겨 있던 지식을 실시간 업무 결정으로 전환하는 메커니즘을 검증했다. 그러나 파이프라인 빌더의 임베딩 보드는 아직 초기 접근 단계이므로, 모든 환경에서의 정식 가용성은 향후 업데이트를 기다려야 한다.

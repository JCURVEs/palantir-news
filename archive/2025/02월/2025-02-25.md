## [Palantir] 팔란티어-마이크로소프트 협력: Army Vantage와 Power BI 연동으로 군 데이터 접근성 강화

**분야:** 국방/공공 | **중요도:** 8점

**원문발행일:** 2025-02-25T14:23:51.619000Z

**수집일:** 2026-10-26

**요약:**  
미 국방부의 데이터 상호운용성 요구에 부응하기 위해 팔란티어의 Army Vantage 플랫폼과 마이크로소프트의 Power BI를 연동하는 협력을 진행했다. Army Vantage는 수백만 개의 데이터 포인트를 통합하여 온톨로지 기반 애플리케이션을 생성하며, 이를 통해 수천 명의 군 작전 요원이 실시간으로 데이터를 분석하고 의사결정에 활용한다. 기존 기본 상호운용성만으로는 부족하다는 사용자 피드백을 반영하여, S3 API 및 REST 연결을 지원하는 확장된 Vantage to Power BI 커넥터를 배포했다. 이 커넥터는 파일 시스템 탐색, 안전한 OAuth 인증, 제3자 애플리케이션 자격 증명 등 Vantage의 기능을 Power BI에서 그대로 유지하면서 데이터를 실시간으로 시각화할 수 있게 한다. 현재 이 데이터 연결은 월 50만 회 이상 사용되며, 군이 생성한 Power BI 대시보드가 최신 Vantage 데이터 제품으로 구동되고 있다. 또한 최근 Vantage에 OpenAI가 통합되어 사용자가 새로운 워크플로우를 개발할 수 있는 기반이 마련되었으나, 이는 향후 확장 가능성을 시사하는 단계이다.

**쉬운설명:**  
군 장병과 지휘관이 사용하는 데이터 분석 도구(Vantage)와 시각화 도구(Power BI)를 직접 연결해, 복잡한 데이터 처리 과정 없이 최신 정보를 대시보드에서 바로 확인할 수 있게 만든 것입니다.

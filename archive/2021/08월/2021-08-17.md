## [Palantir] Envoy 도입을 통한 Rubix의 세밀한 아웃바운드 트래픽 필터링 구현

**분야:** 엔지니어링 | **중요도:** 6점

**원문발행일:** 2021-08-17T20:38:43Z

**수집일:** 2026-10-03

**요약:**  
Palantir 네트워크 인프라 팀은 기존 Squid 프록시에서 Envoy로 전환하여 Kubernetes 인프라(Rubix)의 아웃바운드 트래픽 필터링 방식을 개선했습니다. Envoy의 동적 구성 기능을 활용하여 Foundry 플랫폼에서 트래픽 규칙을 변경할 때 클러스터 재시작 없이 프록시 설정을 자동으로 업데이트할 수 있게 되었습니다. 또한, Envoy가 제공하는 방대한 관측성 데이터를 Datadog과 연동하여 네트워크 상태를 실시간으로 모니터링하고 문제를 신속하게 진단하는 체계를 구축했습니다.

**쉬운설명:**  
회사 내부에서 외부로 나가는 인터넷 접속을 관리하는 '문지기' 역할을 하는 소프트웨어를 기존 구형 제품에서 최신 고성능 제품인 Envoy로 교체했습니다. 이를 통해 보안 규칙을 변경할 때마다 시스템을 껐다 켜는 번거로움을 없애고, 누가 어떤 곳으로 접속하는지 실시간으로 감시할 수 있게 되었습니다.

## [Palantir] PhishCatch: 내부에서 외부로 비밀번호 재사용 탐지

**분야:** 보안/거버넌스 | **중요도:** 5점

**원문발행일:** 2021-03-23T13:02:54.584000Z

**수집일:** 2026-10-08

**요약:**  
PhishCatch는 비밀번호 위생(password hygiene)을 강제하기 위해 개발된 브라우저 확장 프로그램입니다. 이 도구는 사용자가 비밀번호를 재사용하는 행위를 탐지하는 데 초점을 맞추고 있습니다. Palantir 블로그의 해당 게시물은 보안 검증(CAPTCHA) 페이지로 인해 원문 본문 내용이 비공개 상태입니다.

**쉬운설명:**  
PhishCatch는 웹 브라우저에 설치하는 작은 프로그램으로, 사용자가 여러 사이트에서 같은 비밀번호를 쓰지 않도록 도와줍니다.

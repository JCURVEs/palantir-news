## [Palantir] IBM Cloud Pak for Data와 Palantir Foundry 인증 시스템 통합

**분야:** 엔지니어링 | **중요도:** 7점

**원문발행일:** 2021-02-08T19:42:35Z

**수집일:** 2026-10-03

**요약:**  
Palantir와 IBM은 Palantir Foundry의 핵심 모듈과 IBM Cloud Pak for Data를 결합하여 기업 데이터에 AI를 쉽게 적용할 수 있는 파트너십을 발표했다. 이 글은 두 플랫폼의 서로 다른 인증 및 인가(Auth-n/z) 아키텍처를 통합하기 위한 기술적 해결책을 다룬다. Palantir의 Multipass 서비스는 IBM Cloud Pak의 JWT를 검증하여 Palantir JWT로 투명하게 교환함으로써 사용자의 이중 로그인을 방지한다. 또한, Palantir 백엔드 서비스가 Cloud Pak API에 접근할 때 필요한 토큰 교환을 자동화하는 API 게이트웨이를 구현하여 원활한 데이터 상호작용을 지원한다.

**쉬운설명:**  
두 개의 다른 회사 소프트웨어를 함께 사용할 때, 사용자가 매번 다시 로그인하지 않고도 자연스럽게 데이터를 주고받을 수 있도록 하는 '디지털 여권' 교환 시스템을 만들었다는 내용이다.

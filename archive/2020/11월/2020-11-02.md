## [Palantir] 팔란티어 FDSE: 고객 현장에 파견되어 Gotham 플랫폼을 직접 구성하는 엔지니어링 방식

**분야:** 엔지니어링 | **중요도:** 6점

**원문발행일:** 2020-11-02T16:04:54Z

**수집일:** 2026-10-29

**요약:**  
팔란티어의 포워드 디플로이드 소프트웨어 엔지니어(FDSE)는 전통적인 개발자(Dev)가 여러 고객을 위한 단일 기능을 만드는 것과 달리, 특정 고객에게 파견되어 Foundry와 Gotham 플랫폼을 설정하여 해당 고객의 복잡한 문제를 해결하는 역할을 수행한다. 이들은 컨설턴트와 달리 기존 플랫폼의 기능을 재사용하거나 조합하여 빠르고 기술적으로 창의적인 솔루션을 제공하며, 수년에 걸친 패치워크식 개발을 피한다. 현재 미국 국방부 고객을 위해 Gotham 플랫폼 위에 새로운 기능을 구축하는 Brian의 사례에서, 하루 일과는 워크플로 설계 및 테스트, 데이터 모델 구성, 그리고 생산 시스템 모니터링으로 구성된다. FDSE는 테라바이트 규모 데이터 파이프라인 구축, 규제 준수 기반 접근 제어 설정, 그리고 비기술적 사용자를 위한 고노이즈 데이터 시각화 도구 개발 등 구체적인 기술적 과제를 해결한다. 이러한 현장에서의 구성 경험은 내부 제품 개발팀으로 피드백되어 플랫폼의 기본 기능으로 통합되기도 한다. COVID-19 대응 프로젝트처럼 며칠 내에 솔루션을 배포해야 하는 긴급한 상황에서도 즉각적인 피드백 사이클을 통해 실질적인 영향을 주는 소프트웨어를 신속하게 구축할 수 있다.

**쉬운설명:**  
팔란티어의 FDSE는 고객사 현장에 직접 파견되어, 기존에 만들어진 소프트웨어 플랫폼을 고객의 업무에 맞게 조립하고 설정하는 엔지니어입니다. 마치 레고 블록을 가지고 고객의 특정 문제를 해결할 모델을 직접 만들어주는 역할로, 컨설턴트가 조언만 하는 것과 달리 실제 작동하는 시스템을 짧은 시간 안에 구축합니다.

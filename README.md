# Palantir News

**팔란티어의 기술을 업무의 언어로 읽습니다.**

Palantir News는 팔란티어의 공식 발표와 엔지니어링 글에서 기술의 작동 방식과 현장 사례를 골라 한국어로 전하는 독립 큐레이터 채널입니다. 제품 이름만 나열하기보다, 어떤 문제를 풀려고 만들었고 실제 업무에서 어떻게 쓰이는지 살펴봅니다.

**[Palantir News 사이트에서 읽기](https://palantir-news-jcurves.ysinter.chatgpt.site/)**

## 골라 읽는 기술 이야기

- [데이터는 연결됐는데, 왜 업무 앱마다 뜻이 달라질까?](https://palantir-news-jcurves.ysinter.chatgpt.site/article.html?id=399bd1a5971b) ([Palantir 글](https://blog.palantir.com/ontology-finding-meaning-in-data-palantir-rfx-blog-series-1-399bd1a5971b)): 온톨로지 개념을 뉴스레터 형식으로 읽습니다.
- [데이터 접근 권한에 '왜'를 남기는 방법](https://palantir-news-jcurves.ysinter.chatgpt.site/article.html?id=f419faa400b3) ([Palantir 글](https://blog.palantir.com/purpose-based-access-controls-at-palantir-f419faa400b3)): 목적 기반 접근 제어가 권한 신청과 승인 사유를 어떻게 연결하는지 살펴봅니다.
- [Foundry가 설비 데이터를 운영 판단으로 잇는 과정](https://palantir-news-jcurves.ysinter.chatgpt.site/article.html?id=4c644e36b6fc) ([Palantir 글](https://blog.palantir.com/how-palantir-foundry-powers-bps-digital-transformation-in-reliability-4c644e36b6fc)): bp 사례를 통해 분산된 엔지니어링·유지보수 데이터를 한데 보는 이유를 읽습니다.

상세 글은 도입, 구체적인 소제목, 관련 이미지, 검증 범위를 밝힌 마무리로 구성한 한국어 뉴스레터 형식으로 전환하고 있습니다. 아직 전환되지 않은 글은 기존 요약을 표시합니다. 세부 사실은 Palantir 공식 블로그에서 확인할 수 있습니다.

## 주목하는 분야

- **AIP와 AI 에이전트**: AI가 답변을 생성하는 단계를 넘어, 업무 흐름 안에서 안전하게 판단하고 행동하는 방식
- **온톨로지**: 데이터, 업무 규칙, 실행과 권한을 연결해 조직의 현실을 표현하는 설계
- **플랫폼 엔지니어링**: 대규모 데이터 처리와 검색, 보안, 관측성을 실제 서비스에서 다루는 방법
- **현장 적용**: 제조, 공급망, 공공 영역에서 기술이 구체적인 운영 문제를 만나는 장면
